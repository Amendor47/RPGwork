# When You Call Me, Singe

A bilingual (🇫🇷 French / 🇬🇧 English) interactive love story.

> Somewhere between a Discord call and a Swedish winter, two people accidentally fell in love.
> **Lou burns. Elias holds the fire.**

A single-page, dependency-free web experience: branching narrative, an
emotion-decoder quiz, an interactive Sweden map, an SMS-style argument with
multiple endings, a "Are you Lou or Elias?" personality test, collectible
voice notes, a Baudelaire-the-cat easter egg, generated lo-fi audio, pixel
snowfall, and a shareable ending card. Progress and language are saved in
`localStorage`.

## Run it
Open `index.html` in any modern browser, or serve the folder:

```bash
python3 -m http.server
```

## Files
- `index.html` — structure & bilingual content (`data-en` / `data-fr`)
- `styles.css` — warm-orange / dusty-rose / nordic-blue lo-fi design
- `app.js` — story engine, quiz, meters, audio, snowfall, save system
